## 1) GitHub 연동
- 저장소: https://github.com/inchowon58-beep/doodleclub
- Vercel 프로젝트명 예: `poodle-dud` → https://poodle-dud.vercel.app
- Framework: Next.js / Root: `.` / Build: `next build`

## 2) Blob Storage (필수 · 이 프로젝트 전용으로 새로 생성)
- Vercel → poodle-dud(또는 doodleclub) 프로젝트 → Storage → Create → Blob
- 이 프로젝트에만 Connect
- `BLOB_READ_WRITE_TOKEN` 자동 주입 확인
- 다른 사이트(달빛/메종) Blob 토큰을 넣으면 SEO 글이 섞입니다.
